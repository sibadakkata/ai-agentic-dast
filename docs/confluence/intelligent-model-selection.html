Audience: scanner operators and engineers.
Last updated: 2026-05-29.

Auto mode selects Haiku / Sonnet / Opus per scan phase. An optional USD budget cap pauses the scan until the owner or an admin approves a higher limit.

Why Auto mode?

Manual mode uses one model for every phase. Auto mode assigns cheaper models to recon/crawl and stronger models to access control, business logic, and attack-chain phases—typically better coverage per dollar on full OWASP scans.

Phase → tier → model

Policy is implemented in scanners/ai_agent/auto_router.py.

TierModelExample phase IDs
CHEAPHaikuweb_recon, api_recon, crawl_only, passive_recon, dns_enum
BALANCEDSonnetweb_a03_xss, web_a03_sqli, api_injection, api_ssrf, …
PREMIUMOpusweb_a01, api_authz, api_bfla, api_business_logic, attack_chain_analysis, chain_*

Substring overrides: idor, authz, bfla, business_logic, multi_tenant, session_mgmt. Retries with hint.retry promote to PREMIUM.

Worked examples

1. Marketing site recon

Auto + crawl-only → Haiku phases only. Expected ~$0.15. Budget warning unlikely.

2. SaaS OWASP scan with login

Haiku recon, Sonnet vuln phases, Opus for web_a01 and web_session_mgmt. Expected ~$1.50; recommended budget ~$3.

3. Multi-tenant API (BOLA / business logic)

Opus on api_authz, api_bfla, api_business_logic, attack_chain_analysis. Expected ~$4; recommended budget ~$8.

4. Retry after Sonnet failure

Failed phase retry uses hint.retry → Opus for that phase. Audit via Models used by phase in the live scan UI.

Approval gate

  1. ok — scan running; spend tracked.
  2. awaiting_approval — cap reached; scan paused.
  3. Owner or admin clicks Increase budget and resume (or API approve).
  4. approved — scan resumes until new cap.

Only the SSO user who launched the scan or a platform admin may approve (enforced server-side). Approve/stop require an SSO Web UI session — not Basic Auth automation.

Budget caps protect against runaway costs. Only Web UI users (SSO) can change them. API, MCP, and OpenClaw automation always run with the server-side default ($30 for Auto mode, tunable via AUTO_MODE_DEFAULT_BUDGET_USD).

API quickstart

POST /api/scans/estimate
{"scan_mode":"both","scan_intensity":"deep","model_policy":"auto"}

POST /api/v1/scans
{"target_url":"https://staging.example.com","model_policy":"auto"}

GET /api/scans/{id}/budget
(approval_requires_sso: true, default_cap_usd: 30)

MCP (Cursor / Claude Desktop)

Tools: start_scan (model_policy only), estimate_scan_cost, get_scan_budget. Budget cannot be set or approved from MCP.

OpenClaw

Natural language: “Scan staging.example.com in auto mode” → POST body with model_policy: "auto" only (server $30 default cap).

Cost transparency

Per-scan cost in UI; model_choices maps phase → model in auto mode; platform analytics tab for cross-scan spend.
