Auto mode and the budget gate are new (May 2026). This page is a short overview; technical detail lives in the Git repo.

The Red Team AI Web Scanner is internal LLM-driven DAST for authorized web and API testing by Red Team, AppSec, and product teams.

What it does

  • Discovers attack surface on sites, SPAs, and APIs (Playwright + HTTP tools).
  • Runs OWASP-aligned phases (XSS, SQLi, SSRF, IDOR/BOLA, auth flaws, and more).
  • Imports Postman, Burp, or Swagger/OpenAPI for API coverage.
  • Streams live progress; exports PDF, Excel, or JSON when done.
  • Tracks LLM cost per scan and in Cost Analytics.

How to run a scan

Web UI (recommended): http://3.20.180.251 → SSO → New Scan.

Automation: REST API (docs/api.md, Swagger), MCP (docs/mcp.md), or OpenClaw (openclaw-skill/README.md) — see Git for setup; budget approval is Web UI only. For scan IDs, polling, and post-approval resume, see the [Red Team AI Web Scanner — Automation: MCP, OpenClaw, REST API|Red Team AI Web Scanner — Automation: MCP, OpenClaw, REST API] child page.

Only scan targets you are authorized to test. The scanner performs active attacks (injection, auth bypass probes, and similar). Misuse may violate policy and law.

Ways to scan

  • Website, API, or Both — one job covers site plus APIs when needed.
  • Imports — Postman, Burp, or Swagger/OpenAPI.
  • Business flow — describe a multi-step journey in plain language.
  • Intensity — Light, Standard, or Deep; Crawl only skips attack payloads.

Choosing a model

  • Manual (default): One model (Haiku, Sonnet, or Opus) for all phases.
  • Auto (new): Haiku, Sonnet, or Opus per phase for cost vs. quality.
  • Opus on hard phases: access control, business logic, session mgmt, attack chains.
  • Live cost on the scan page; Auto shows Models used by phase.
  • For automation usage (MCP, OpenClaw, REST API), see the [Red Team AI Web Scanner — Automation: MCP, OpenClaw, REST API|Red Team AI Web Scanner — Automation: MCP, OpenClaw, REST API] child page.

Budget gate

  • Auto mode default cap: $30 USD per scan (server-side).
  • Custom cap: Web UI scan form (SSO). API/MCP/OpenClaw keep $30 — prevents runaway automation cost.
  • At cap, scan pauses until the starter or an admin approves more budget in the Web UI.
